Comment ça marche

Le haut de la page est une section HTML ordinaire : un titre, un paragraphe, un lien. Le navigateur la met en page ; on en tire une image, posée comme une encre sur une étoffe dont chaque point est simulé sur le GPU : une grille de particules intégrée en Verlet, retenue par des contraintes de distance (trame, chaîne, biais, flexion) résolues en parallèle, seize fois par demi-image. Le mur arrête le tissu, la main le soulève vers vous, l'ombre se décale avec la hauteur.

L'image du HTML vient de HTML-in-Canvas quand le navigateur l'expose (Chrome, essai d'origine, versions 155 à 160) : la section devient l'enfant d'un canvas content="drawable", le navigateur la dessine lui-même dans une texture (drawElementImageToTexture), et ses zones de clic suivent. Ailleurs, Presse relit la mise en page — chaque lettre à sa place, chaque fond, chaque bordure — et la réimprime dans un canvas : le même principe que tout le reste de ce site. Changez le titre : l'encre suit.

Le lien reste un lien : au clavier, et à la souris quand le drap est à plat. D'après une démo partagée sur X (« HTML in canvas API so all the text and buttons are actual HTML from our website printed onto a fabric texture simulated in WebGPU »), refaite ici sans reprendre son code ; les étoffes sont procédurales.
