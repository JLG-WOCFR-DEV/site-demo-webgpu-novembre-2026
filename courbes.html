Presse · registre du mouvement

Courbes

Une courbe dit comment le temps traverse un mouvement : vite puis lentement, avec un dépassement, par à-coups. Ici, une seule écriture — celle de CSS — pour le navigateur, le moteur de temps de Presse et les effets : data-anim-ease, data-cinetique-courbe, data-goo-courbe, data-couloir-courbe.

Éditeur

Tirez une poignée, ou prenez-la au clavier : flèches pour un centième, Maj pour un millième. La balle est animée avec la valeur produite ; la pastille sur le graphe, par la fonction JavaScript. Elles doivent dire la même chose.

Comparer

Quatre courbes, même durée, même départ, animées par la Web Animations API. La première suit l'éditeur.

    Dans une page

    La valeur de l'éditeur, posée sur les effets qui l'acceptent (les durées suivent le ressort quand il y en a un).

    <h2 data-anim="monte" data-anim-ease="out">…</h2>
