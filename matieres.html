Matières

Trois matières que le GPU fabrique sous le pointeur : un tissu de paillettes, des lettres faites d'eau, d'éclair et de feu, et un diagramme de phase qui respire.

01

Paillettes

Brossez le tissu : chaque paillette bascule dans le sens du geste. Vers le haut, elle montre sa face cachée ; vers le bas, l'argent revient.

D'après les paillettes interactives de しゅん / LIG (three.js). Refait en WebGPU.

02

Eau, éclair, feu

Le mot est dessiné dans un canvas, le GPU en lit les pixels et en fait une matière. Passez le pointeur : l'eau se ride, le courant saute vers vous, les flammes se couchent.

D'après les trois kanji (水 雷 炎) de しゅん / LIG (three.js). Refait en WebGPU.

03

Diagramme de phase

Des formes en champ de distance dérivent ; là où elles se touchent, leurs champs fusionnent. On n'en dessine que les lignes de niveau, en couches, comme les frontières entre les phases d'un matériau. Le pointeur est une forme de plus (ou un creux). Tournez le cadran : le champ s'étire dans ce sens.
