Mise en page liquide

Sept photos, sept cartes HTML dans une grille CSS. Glissez-en une, mélangez, filtrez : le navigateur fait la mise en page, le GPU rend chaque carte en verre, qui s'étire quand elle file et fusionne avec ses voisines quand elles se frôlent.

Comment c'est fait

La grille est du CSS ordinaire. Pour réordonner, le script déplace les éléments dans le DOM puis anime l'écart avec un ressort (la technique FLIP) ; le navigateur reste maître de la mise en page. À chaque image, le moteur lit le rectangle de chaque photo, en déduit sa vitesse, et la transforme en une forme molle : elle s'étire dans le sens du mouvement, se tasse à l'arrêt, s'arrondit quand elle file.

Le GPU calcule ensuite, pour chaque pixel, la distance à chaque carte, et les fond par un minimum lissé : là où deux cartes se frôlent, un pont de verre les relie, et ses couleurs mêlent celles des deux photos. Le bord est une lentille : la normale du champ dévie la lecture de la photo, avec une légère dispersion des couleurs et un reflet. Au repos, les cartes redeviennent des rectangles arrondis exacts.

D'après l'exemple « Liquid Layout » de vgpu, réécrit en WebGPU brut. Le texte, les légendes et les images restent dans le HTML : sans WebGPU, ou avec le mouvement réduit, la grille fonctionne de la même façon, sans le verre.
